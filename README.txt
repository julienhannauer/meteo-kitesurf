# Météo & Kitesurf — PWA

Cette version reprend le dernier HTML et la nouvelle icône kitesurf.

Pour mettre à jour GitHub Pages :
1. Dans le dépôt `meteo-kitesurf`, remplace `index.html`, `manifest.webmanifest` et `sw.js`.
2. Ajoute `icon-kite-180.png`, `icon-kite-192.png` et `icon-kite-512.png`.
3. Commit les changements.
4. Sur le téléphone, ferme/réouvre l'app. Si l'ancienne icône reste, supprime l'app de l'écran d'accueil puis réinstalle-la depuis Chrome.
